# Cutre

> [日本語](./README.md) | English

Trade the cute things!

Cutre is still under development and has not been released to the public.

[![Go CI](https://github.com/cutreapp/cutre/actions/workflows/go-ci.yml/badge.svg)](https://github.com/cutreapp/cutre/actions/workflows/go-ci.yml)

Cutre is developed in Japanese.
Code comments, documentation, commit messages, and pull requests are written in Japanese, and the Japanese documents are the source of truth.
This page and a few other entry documents are English translations provided for reference.

## About Cutre

Cutre is a service that makes trading character goods simple.
The aim is to let you register the goods you want and the ones you can part with, and find someone to trade with.
